# SGA Instagram carousel

Turn a supplied post, screenshots, or a [`content-reseach`](../content-reseach/SKILL.md) brief into an SGA carousel. Match the source's audience psychology and flow while writing original copy and using original visual treatment.

1. **Read the source completely.** Inspect every reference slide or all text in the post, including the ending and caption when available. Record core message, and rhetorical style (for example, contrast, reveal, or concise tips).
2. **Draft copy slide by slide.** Preserve the sequence of hook, tension, explanation, and payoff where it works. Reframe examples and takeaways for SGA's audience without copying distinctive wording. Write in natural Indonesian with an “aku–kamu” voice and no emojis.
3. **Verify claims.** Check technical, product, and numerical claims against credible sources or provided SGA materials.
4. **Revise from feedback.** Apply the user's wording changes to the slide copy, then recheck any affected claim or slide transition.
5. **Create images only when the user asks.** Produce one separate Instagram image per slide at a 4:5 aspect ratio. Keep a coherent SGA design, choosing colors to suit the content; blue and yellow are brand cues, not a mandatory palette for every slide. If a person would help a tutorial or tip, use the user's ambassador character sheet image when supplied and suitable. Request the sheet if the user's likeness is needed but the file is unavailable.
6. **Write the caption.** Provide a short, natural Indonesian caption with searchable topic terms and a context-appropriate invitation to respond or save. Avoid generic AI phrasing and unsupported promises.

The deliverable is numbered copy, a short claim/source note where verification affected the wording, the caption, and, only when requested, individually accessible slide images. If research was part of the request, retain the source URL and explain the adapted hook briefly.
